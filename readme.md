RFX Reworks is a decorative scifi resource pack in a semi-vanilla visual style for modded Minecraft 1.12.2, with variations in progress for later versions. It modifies a number of sprites to be more interesting and flashy, with a bit of scifi flair; or just slightly more aesthetically appealing.
It is designed for use with Optifine or [Fabulously Optimized](https://modrinth.com/modpack/fabulously-optimized?hl=en-US), which I highly recommend.

This project is effectively open source. Project files will be included in a separate branch eventually, but on request I am more than happy to provide all of them sooner for use in your own projects or just general perusal. They are in the .kra format, an open-source storage format for the Krita art program.

Items contained in the "extras" folder are items that don't necessarily represent anything that actually exists yet. They're basically just sketches or sprites I made for fun, included for whatever use they might end up having.
